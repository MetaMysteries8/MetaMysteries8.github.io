# MainVoice Synth — static hosted build

Upload the **contents of this folder** to any ordinary static host.

Examples: GitHub Pages, Cloudflare Pages, Netlify, Vercel static hosting,
Neocities, nginx/Apache, or any basic HTTP file host.

No Python/API/backend is needed after this folder is generated.

The full MainPack recorder + waveform editor is included as `mainpack setup.html`.
Visitors can load/edit/export their own ZIP entirely in-browser.

The `mainvoices/` directory is always present. Official voice discovery uses
`mainvoices/voices.json`, which is regenerated by `build-static.bat`; simply
copying a new folder into an already-built static site cannot update that manifest
automatically because browsers cannot enumerate server directories.

Important: every official voice pack in `mainvoices/` is public in a hosted build.
Visitors can download the raw WAV phoneme samples and read `voice.json`.
