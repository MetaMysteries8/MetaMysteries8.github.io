SOL — MainVoice voice pack
==========================

This is an original synthetic 39-phoneme MainVoice pack generated from scratch.
It is not a recording or clone of a human speaker.

INSTALL
-------
1. Unzip this archive.
2. Copy the inner "sol" folder into your project's mainvoices/ directory.
3. Local build: refresh the app.
4. Static build: rebuild voices.json / run build-static.bat before redeploying.

CONTENTS
--------
voice.json
character.png
samples/*.wav

The bank uses the MainVoice ARPAbet-39 layout and a stable ~196 Hz base pitch.
